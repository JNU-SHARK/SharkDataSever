# 矢量化传输快速开始

## 功能说明

使用LoG边缘检测将图像转换为矢量线段，只传输线条端点，大幅减少数据量（压缩率可达95%+）。

## 使用步骤

### 1. 选择矢量化模式

在Web界面的自定义数据发送区域：

```
通道: [📐 矢量化(LoG)]  ← 选择这个选项
```

### 2. 上传图片

点击"选择图片"按钮，上传要处理的图像。

### 3. 查看处理结果

- 浏览器控制台会显示提取的线段数量
- 预览区域显示矢量化后的效果（白底黑线）
- 显示压缩后的数据大小

### 4. 发送数据

点击"发送自定义数据"按钮，矢量数据会自动编码并通过ImageBlock传输。

## 数据格式

```
Header (6 bytes):
  - width: 2B (原图宽度)
  - height: 2B (原图高度)
  - lineCount: 2B (线段数量)

Lines (lineCount × 8 bytes):
  每条线段:
  - x1, y1: 起点坐标 (各2B)
  - x2, y2: 终点坐标 (各2B)
```

## C语言解码示例

```c
// 解析头部
uint16_t width = (data[0] << 8) | data[1];
uint16_t height = (data[2] << 8) | data[3];
uint16_t lineCount = (data[4] << 8) | data[5];

// 解析线段
for (int i = 0; i < lineCount; i++) {
    uint8_t* ptr = data + 6 + i * 8;
    uint16_t x1 = (ptr[0] << 8) | ptr[1];
    uint16_t y1 = (ptr[2] << 8) | ptr[3];
    uint16_t x2 = (ptr[4] << 8) | ptr[5];
    uint16_t y2 = (ptr[6] << 8) | ptr[7];
    
    // 绘制线段
    draw_line(x1, y1, x2, y2);
}
```

## 性能对比

| 格式 | 数据量 | 压缩比 |
|------|--------|--------|
| JPEG | ~20KB | - |
| 位图 | 76KB | - |
| **矢量** | **0.8-3KB** | **95%+** ✨ |
