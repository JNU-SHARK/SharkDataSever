# 矢量化 vs AVIF 压缩对比分析

## 问题：为什么矢量化比AVIF二值化体积大？

### 简短回答
**矢量化不总是更小** - 取决于图像复杂度！

- **简单图像（<50条线段）**: 矢量化 **更小**
- **复杂图像（>200条线段）**: AVIF二值化 **更小**

---

## 详细分析

### 1. 数据格式对比

#### AVIF 二值化（位图格式）
```
原始图像: 320×240 = 76,800 像素
二值化后: 76,800 bit = 9,600 字节
AVIF压缩: ~500-1500 字节 (压缩比 85-95%)
```

**特点**:
- 不管图像多复杂，压缩后体积相对稳定
- AVIF对二值图（黑白图）压缩效果极佳
- 适合复杂纹理、大量细节

#### 矢量化（端点格式）
```
数据结构:
  Header: 6 字节 (宽度2B + 高度2B + 线段数2B)
  每条线段: 8 字节 (x1,y1,x2,y2 各2B)

总大小 = 6 + (线段数 × 8) 字节
```

**示例**:
- 10条线段: 6 + 80 = **86字节** ✅
- 50条线段: 6 + 400 = **406字节** ✅
- 100条线段: 6 + 800 = **806字节** ⚠️
- 200条线段: 6 + 1600 = **1606字节** ❌
- 500条线段: 6 + 4000 = **4006字节** ❌❌

---

### 2. 何时矢量化体积更大？

#### 原因分析

1. **线段数量爆炸**
   - 复杂图像边缘检测会产生大量短线段
   - 每条线段固定占用8字节
   - 没有进一步压缩

2. **AVIF的块压缩优势**
   - AVIF使用块级编码（类似视频压缩）
   - 对大片白色区域压缩率极高
   - 二值图只有0和1，熵很低，压缩效果好

3. **矢量化没有优化**
   - 当前实现：连通分量的首尾端点
   - 未进行线段合并（共线线段应合并）
   - 未过滤极短线段（噪声）
   - 未使用差分编码（相邻坐标通常相近）

### 4. 优化方案

#### 方案A: 线段优化（推荐）

1. **合并共线线段**
```javascript
// 检测共线并合并
function mergeCollinearLines(lines) {
    // 按斜率分组，合并同方向线段
    // 可将线段数减少 30-60%
}
```

2. **过滤噪声**
```javascript
// 过滤极短线段
const minLength = 3; // 少于3像素的线段视为噪声
lines = lines.filter(line => {
    const dx = line.x2 - line.x1;
    const dy = line.y2 - line.y1;
    return Math.sqrt(dx*dx + dy*dy) >= minLength;
});
```

3. **差分编码**
```c
// 使用相对坐标而非绝对坐标
// 首条线段: x1(2B) y1(2B) x2(2B) y2(2B)
// 后续线段: dx1(1B) dy1(1B) dx2(1B) dy2(1B)  // 相对前一条线段
// 节省空间: 50%
```

#### 方案B: 自适应选择

### 5. 建议使用场景

#### ✅ 优先使用矢量化:

- **工程图纸**: 直线为主，<30条线段
- **简单路径**: 导航路径、轨迹
- **二维码**: 规则矩形，<20条线段  
- **示意图**: 框图、流程图

**判断标准**: 线段数 < 100

#### ✅ 优先使用AVIF:

- **自然场景边缘**: 复杂曲线
- **文字识别**: 大量笔画
- **纹理图案**: 不规则边缘
- **照片轮廓**: >200条线段

**判断标准**: 线段数 > 150

#### ⚖️ 两者相当:

- 线段数在 100-150 之间
- 建议实际测试选择

### 7. 总结

| 特性 | 矢量化 | AVIF二值化 |
|------|--------|-----------|
| 简单图像 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |
| 复杂图像 | ⭐⭐ | ⭐⭐⭐⭐⭐ |
| 压缩比（最好） | 99%+ | 95% |
| 压缩比（最差） | 50% | 90% |
| 解码速度 | 极快（直接绘线） | 快（解压缩） |
| 兼容性 | 需自定义解码 | 标准格式 |
| 可扩展性 | 高（可放大无损） | 低（位图） |

**推荐策略**: 
- 实测后根据线段数量选择
- 简单图 → 矢量化
- 复杂图 → AVIF
- 或实现自动选择逻辑
